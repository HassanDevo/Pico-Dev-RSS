# Pico Dev language packs

This folder holds the language index (`index.json`) and the saved packs used by Pico Dev.

Pico Dev downloads `index.json` from this repository and then fetches each pack by the `path` recorded in the index. Every pack entry includes the file size and SHA-256 so downloads can be verified.

The packs were copied from the AntiGem beta resources and rebranded for Pico Dev.
