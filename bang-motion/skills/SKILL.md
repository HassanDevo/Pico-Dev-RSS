# Bang Motion — Pico Dev skill entry

The full, original skill guide is `../SKILL.md` at this plugin's root. All of its referenced files
resolve standalone from this plugin: `../assets/`, `../references/`, `../scripts/`, `../docs/`,
`../README.md` and `../CHANGELOG.md`.

Use it whenever the user asks for a promo video, opener, intro, bumper, kinetic typography,
cinematic text animation or an explainer built as a single HTML file. Follow the full guide for the
scene, camera, typography, audio and render rules; do not substitute a slide deck.
